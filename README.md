📘 Student Result Management System

Java Programming – Assignment 3
K.R. Mangalam University

This project is a menu-driven Java application that manages student results.
It demonstrates Exception Handling, including:

Built-in exceptions

Custom exception (InvalidMarksException)

try–catch blocks

throw and throws

finally

Input validation

Arrays of objects

This fulfills all requirements given in the assignment PDF.

🚀 Features
✔ Add Student

Takes Roll Number, Name, and 3 subject marks

Validates marks (0–100)

Throws custom exceptions for invalid input

✔ Show Student Details

Search by Roll Number

Displays marks, average, and pass/fail result

✔ Exception Handling Demonstrated

InvalidMarksException (Custom)

InputMismatchException

NumberFormatException

try, catch, throw, throws, finally

✔ Uses Arrays to Store Multiple Students

Up to 100 students can be stored.


🛠 Technologies Used

Java SE 8+

OOP (Classes, Objects, Methods)

Exception Handling

Arrays
